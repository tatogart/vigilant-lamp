# CodeClaw 🦞 — офлайн код-ассистент в браузере

Черновик «своего Claude Code» для мобилы и ПК: нейросеть для кода работает
**полностью в браузере** (WebLLM + WebGPU), **офлайн** после первой загрузки модели,
устанавливается как PWA, деплоится на **GitHub Pages** (чистый статический хостинг).

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | UI: чат, оверлей загрузки модели, компоновка для мобилы/ПК |
| `app.js` | Инициализация WebLLM, стриминг-чат, рендер код-блоков с копированием, PWA-install |
| `sw.js` | Service worker: офлайн-кэш shell + CDN-скрипта |
| `manifest.webmanifest` | Манифест для установки на домашний экран |

## План на 4 часа

**Час 1 — скелет (готово).** PWA-манифест, service worker, адаптивный UI чата.
Деплой на GitHub Pages: Settings → Pages → ветка `main`, корень. Проверить, что
сайт открывается по HTTPS (обязательно для WebGPU и SW).

**Час 2 — модель.** Подключение `@mlc-ai/web-llm`, модель
`Qwen2.5-Coder-1.5B-Instruct-q4f16_1` (~1 ГБ). Прогресс-бар загрузки,
кэш в IndexedDB → второй запуск без сети. Тест на ПК в Chrome/Edge.

**Час 3 — функции «как у Claude Code» (упрощённо).** Стриминг ответов,
код-блоки с кнопкой копирования, системный промпт, контекст последних
сообщений, авто-рост textarea.

**Час 4 — полировка и мобила.** `viewport-fit=cover`, safe-area, тест на Android
Chrome (WebGPU), кнопка «Установить», README.

## Ограничения (честно)

- **WebGPU обязателен.** iOS Safari — только экспериментально; Android — Chrome
  с флагом `chrome://flags/#enable-unsafe-webgpu` на части устройств; ПК — Chrome/Edge.
- Модель 1.5B — это «умный автокомплит», не агент. Для агентства нужна 7B+ и много RAM.
- GitHub Pages отдаёт ~10 ГБ/мес трафика — модель качается с CDN MLC, не с Pages, так что ок.

## Локальный запуск

```bash
npx serve codeclaw        # или любой статический сервер
# открыть http://localhost:3000 в Chrome/Edge
```
